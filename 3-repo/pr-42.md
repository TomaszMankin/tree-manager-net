## What
Adds automatic update checking and installation via Velopack, integrating with GitHub Releases. Updates are checked on app launch (non-blocking, fire-and-forget); if available, user is prompted with a Polish dialog. Download and restart are orchestrated via UpdateCoordinator with comprehensive error handling for non-managed installs.
